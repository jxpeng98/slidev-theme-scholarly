# 学术工作流

先从演示场景出发，再进入对应模板、布局、组件和主题建议。这样比直接浏览完整参考页更快。

| 工作流 | 起步方式 | 适用场景 |
|--------|----------|----------|
| [论文报告](./paper-talk) | `paper-talk` 模板 | 汇报一篇论文或自己的会议论文。 |
| [学位答辩](./thesis-defense) | `thesis-defense` 模板 | 需要论证、证据、局限、答辩问题和附录导航。 |
| [文献综述](./literature-review) | `reading-group` 或 `seminar` 模板 | 比较论文、研究空白和方向。 |
| [结果密集型报告](./results-heavy) | `conference-lightning` 或 `paper-talk` 模板 | 以指标、消融和实验结果为主线。 |
| [课程讲义](./course-lecture) | `basic` 或 `academic` 模板 | 讲概念、定义、例子和总结。 |

如果你在调整视觉可读性，先阅读[主题模式与对比度](../theme-mode-contrast)。
