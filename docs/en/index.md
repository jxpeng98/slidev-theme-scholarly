## Start with a working deck

Create your first project with [Quick start](./guide/quick-start), or draft an outline in the [VS Code extension](./guide/vscode-extension). Both produce Markdown you can continue editing in Slidev.

For a paper talk, thesis defense, literature review, results talk, or lecture, [Academic Workflows](./guide/workflows/) helps you choose a template and slide sequence. Upgrading a deck? Read the [upgrade notes](./guide/upgrade).
